# Moderator script and interview guide

Read the scripts word for word so every participant hears the same thing.

## Day 0, after the pre-test

"This is Clipcademy, a review app for the DNA replication and DNA repair material from class. Enter your participant code. Today, please stay on DNA replication and use it however you normally would to review synthesis direction and primers. Stop whenever you like. Nothing here affects your grade."

If the participant opens DNA repair anyway, don't stop them. Record it as a deviation.

Record any help as assistance. Explain a button only if the participant can't continue. Record abandoned steps and technical failures.

**Scripted follow-up task.** Use this only if the participant never answered a question wrong:

"Tap Restart. Answer the first question however you like. On the primer question, choose answer B on purpose, so we can see what happens after a wrong answer. Watch the explanation, answer the next question, and return home."

Record that the script was used (`scripted_followup_used`). The script by itself doesn't count as assistance. Any other help does.

Then say:

"The app will stay available for the next two days, with both lessons open. Use it if and when you want to. We won't send reminders."

## Day 2, after the post-test

Ask the open questions first.

1. What did you think this tool would do when you first opened it?
2. Where did you hesitate or get confused?
3. Did you open it again after the first session? Which lesson did you use, and why or why not?
4. What did the follow-up explanation change for you, if anything?
5. When you answered in the app, did you pull the answer from memory, or recognize it from the choices?
6. How did this compare with how you studied for your last exam?
7. When would you choose to use it next?
8. What would stop you from using it?

Then ask for clarity and usefulness ratings from 1 (very low) to 5 (very high). Ratings and stated intentions supplement the logged activity. They don't count as actual use.
