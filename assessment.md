# Draft independent concept checks

Based on Lecture 19 pp. 1–2. Have a course-knowledgeable reviewer check the questions and rubric before testing. Keep these checks out of the app's practice bank. Use the same forms and scoring rules in both conditions. These short forms are proposed and have not been validated for equal difficulty.

## Form A — pre-check

1. In which direction is a new DNA strand synthesized? One point for 5′ to 3′.
2. At which end does DNA polymerase add the next nucleotide? One point for the growing strand's 3′ end.
3. Why is a primer needed before DNA polymerase extends a strand? One point for identifying the need for an existing complementary start that polymerase can extend. Mention of primase alone is insufficient.

## Form B — immediate post-check

1. A diagram shows a growing strand with a labeled 3′ end. At which end should the next nucleotide be added? One point for 3′.
2. A learner says that DNA polymerase makes a complementary strand from scratch. Explain the mistake. One point for saying polymerase requires an existing complementary start/primer.
3. Name the enzyme that makes the RNA primer. One point for primase.

## Form C — delayed check

1. A complementary primer is already attached to a template. Name the end extended by DNA polymerase. One point for 3′.
2. State the overall direction of synthesis as new nucleotides are added. One point for 5′ to 3′.
3. Explain the distinct jobs of primase and DNA polymerase at the start. One point only if the response identifies primase making the RNA primer and polymerase extending the started strand.

Use 0 or 1 for each item, total 0–3. Score uncertain responses using the prereviewed rubric. Resolve disagreements without seeing the student's condition where feasible. The two forms emphasize slightly different knowledge, a limitation to report. Do not present repeated exposure to very similar items as proof of durable mastery.
